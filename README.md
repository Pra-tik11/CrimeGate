# 🛡️ CrimeGate — Online Crime Reporting System

![CrimeGate Banner](https://images.unsplash.com/photo-1589578228447-e1a4e481c6c8?w=1200&auto=format&fit=crop)

> **CrimeGate** is a full-stack web-based online crime reporting and management system
> built for Maharashtra Police. Citizens can file FIRs online, track case status in
> real-time, and connect with assigned officers — all digitally.

## ✨ Features

- ✅ **Citizen Portal** — Register, file complaints, upload evidence, track status
- ✅ **Officer Portal** — View assigned cases, update status, add remarks
- ✅ **Admin HQ Portal** — Full dashboard, manage officers, stations, users
- ✅ **JWT Authentication** — Secure login for all 3 portals
- ✅ **Real-Time Status Tracking** — Submitted → FIR Filed → Identified → Caught → Closed
- ✅ **Evidence Upload** — Photos, videos, documents via Multer
- ✅ **Location-Based Assignment** — GPS auto-assigns nearest station
- ✅ **Fully Responsive** — Works on mobile, tablet, desktop
